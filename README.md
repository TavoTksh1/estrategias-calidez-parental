# SofiTV · Foro de Videos

Foro de videos con calificaciones (1-5 estrellas) y comentarios. Sitio estático para GitHub Pages.

- Videos por enlace (YouTube / Vimeo / .mp4); comentar y calificar requiere registro.
- Demo admin: `admin@sofitv.com` / `admin123` (publica videos y modera comentarios).
- Los datos se guardan en `localStorage` del navegador (demo sin backend). Ver `Requerimientos y Plan de Acción - Foro de Videos.md` para el plan completo.
